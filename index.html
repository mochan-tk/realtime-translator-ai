リアルタイム翻訳AI

録音した声を AIで文字起こし（gpt-transcribe）→ GPT で翻訳 → AI音声で読み上げ する通訳アプリです。あなたのOpenAI APIキーを下の設定に入れると、ブラウザから直接OpenAI APIを呼ぶAI経路で動きます。キー未設定の間は、ブラウザ認識＋無料翻訳の経路で動きます。

待機中 AI経路：キー未設定（無料経路で動作） 音声認識：確認中… 読み上げ：確認中… 処理 — ms

OpenAI APIキーの設定（BYOK：キーはあなたのもの）

音声合成モデル（gpt-4o-mini-tts / tts-1）は 2027-01-06 で提供終了予定です。終了後は「読み上げ方式」を端末の音声合成に切り替えるのが代替になります。

キーはこの端末のブラウザ内（localStorage）にだけ保存され、このページのソースやリポジトリには一切含まれません。アプリはブラウザから直接 api.openai.com を呼びます（中継サーバーは使いません）。 ただし localStorage は同一オリジン（同じドメイン）で動く他のページからも読み取れる仕様です。共有端末では使わず、使い終わったら「キーを削除」で消してください。APIの利用料金はあなたのOpenAIアカウント（APIクレジット等）から引かれます。

セットアップ手順（3ステップ）＆ GitHub Pagesへの置き方

  1. ChatGPT設定で組織をリンク：ChatGPT の Settings → Billing で「組織をリンクする」を押し、個人用のAPI組織を選ぶ（月$200分のAPIクレジットがその組織で使えるようになります。リンク先の組織選びは原則やり直しが利かないので慎重に）。
  2. platform.openai.com でAPIキーを作成：その組織の API keys ページで、このアプリ専用のキーを新規作成する。
  3. このアプリに貼る：上の「OpenAI APIキーの設定」にキーを貼って「キーを保存してAI経路を使う」を押し、「接続テスト」で疎通を確認する。キーはこの端末のブラウザ内にだけ保存されます。

単体HTMLにAPIキーは含まれません（キーは端末のlocalStorageに保存されるため）。Pages版でも、使う端末ごとにキーを設定してください。
